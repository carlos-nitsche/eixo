# EIXO OS 0.9.0 — Whisper local no microfone

Data: 15/10/2026. Diretório: C:\Jogos\EIXO.

## Objetivo e resultado
O botão de microfone agora **grava, decodifica e transcreve automaticamente português brasileiro** em um Web Worker do navegador, usando a biblioteca open source [Transformers.js](https://github.com/huggingface/transformers.js) e o modelo multilíngue [Xenova/whisper-tiny](https://huggingface.co/Xenova/whisper-tiny). Não requer API externa, conta no Hugging Face ou credencial; áudio e inferência permanecem no dispositivo.

## Implementação
- Dependência `@huggingface/transformers@3.8.1`.
- Worker `src/whisper-local.worker.ts` usa `automatic-speech-recognition`, `device:'wasm'`, `dtype:'q8'`, `language:'portuguese'`, `task:'transcribe'`.
- Arquivos ONNX, tokenizers e runtimes WASM são instalados por `npm run voice:install` em `public/models` e `public/whisper-wasm`, servidos pela própria origem do EIXO. Nenhum download de modelo ocorre dentro do worker: `env.allowRemoteModels=false`.
- Os pesos são baixados **uma vez na instalação** do repositório público e não enviados ao GitHub. O script pode ser reexecutado, conferindo arquivos já existentes. Depois, `npm run build` para copiar os arquivos locais para a distribuição `dist/`.
- O navegador grava com `getUserMedia` / `MediaRecorder`, decodifica o áudio e reamostra para PCM mono 16 kHz via Web Audio API, transferindo Float32Array ao worker por transferência de memória.
- Ao parar, a transcrição é automática, com indicador de progresso e cancelamento. Resultado aparece no campo de mensagem; o usuário revisa e envia. **Nenhum registro é criado sem o passo de confirmação já existente**.
- Erros não causam perda do áudio: mostra botão de tentar novamente, reproduzir, descartar ou guardar a gravação na memória desta conversa. Nenhum áudio é feito upload.
- Worker permanece aquecido entre mensagens para evitar reiniciar o modelo; é encerrado ao sair/trocar de workspace/cancelar.
- `api/server.mjs` inclui MIME corretos para `.mjs` e `.wasm`, CSP permitindo somente WebAssembly na própria origem (`wasm-unsafe-eval`) e `media-src 'self' blob:`, preservando `connect-src 'self'`.
- O parser local recebeu suporte a horários falados por extenso, como “às quatorze horas” e “às vinte e três horas”; não presume o horário quando o reconhecimento é ambíguo.

## Segurança e limitações
- Não há API externa de transcrição, nem rede para inferência; downloader inicial visita Hugging Face para obter o modelo **sem áudio**. Durante o teste, todas as conexões externas do navegador foram bloqueadas, e a transcrição foi concluída mesmo assim.
- Modelo tiny é compacto, rápido e tem erros em palavras e números; exige revisão antes de confirmar compromissos ou finanças. Em teste com fala sintética pt-BR, “quatorze” foi reconhecido como “quatro” em uma execução; isso mostra a necessidade de revisão manual.
- Arquivos do modelo/WASM totalizam dezenas de MB. Modelos são específicos ao host de cada instalação; não são incluídos no repositório por tamanho. Atualizar o EIXO hospedado com uma versão SaaS do chat exigirá provisionar esses arquivos no host próprio.
- Chrome e Chromium testados em PC. Em celular/iPhone/Android, WebAssembly pode ser mais lento e depender do navegador, permissões, HTTPS e memória disponível; não há validação real em iPhone nesta versão.
- Testes E2E reais requerem dispositivo Windows com voz pt-BR SAPI ou fixture de fala: `tests/whisper-real-e2e.mjs` usa arquivo local `.qa-portuguese.wav` para evitar TTS remoto. O arquivo é temporário e não deve ser publicado.
- A prévia pública Render continua somente marketing, sem interface autenticada nem cobrança Asaas real.

## Validação no Windows
1. `npm ci`
2. `npm run voice:install`
3. `npm run build`
4. Inicie o servidor normal do EIXO e autentique-se.
5. Abra Assistente EIXO → microfone → fale por 3–8 segundos → parar → aguarde "Transcrição local concluída".
6. Revise o texto, clique em Enviar; confira o cartão e confirme para salvar.

## Testes efetuados
- Transcrição de fala pt-BR sintetizada offline no Windows via Microsoft Maria Desktop → Chromium headless → MediaRecorder → Web Worker → Whisper multilingual ONNX q8 → caixa de texto do chat.
- Zero requisições externas durante a inferência no browser interceptado.
- Tempo medido de inferência: aproximadamente 10 s no ambiente Windows testado.
- Regressão do chat: criação/confirmar/cancelar gastos e compromissos, responsividade, isolamento por workspace.
- Suíte de testes completa, proteção de produção e build TypeScript/Vite.
