# EIXO OS 0.9.2 — Safari iOS: Whisper WASM bloqueado por CSP antiga

Data: 15/10/2026. Projeto principal: C:\Jogos\EIXO.

## Sintoma reportado
No iPhone o áudio é gravado mas a inferência Whisper falha: `no available backend found`, `Aborted(CompileError: Refused to create a WebAssembly object because 'unsafe-eval' or 'wasm-unsafe-eval' is not an allowed source ... CSP 'script-src self')`.

## Diagnóstico
- O código da API atual e as respostas HTTPS ativas em home/index/arquivos do Whisper já contêm `script-src 'self' 'wasm-unsafe-eval'`.
- O aplicativo estava usando `sw.js` com cache `eixo-static-v5` que também podia armazenar workers de voz dentro de `/assets/`. Uma resposta JavaScript antiga podia voltar de cache offline, junto com a política de segurança usada antes da correção.
- O aplicativo não tinha teste direto de compilação WASM dentro do contexto real do Web Worker para distinguir CSP de outros problemas de ONNX.

## Alterações
1. `public/sw.js`: cache atualizado de `eixo-static-v5` para `eixo-static-v6`. O processo de ativação exclui caches EIXO antigos. O worker do Whisper `/assets/whisper-local.worker-*.js` é explicitamente excluído do cache do Service Worker.
2. `src/main.tsx`: registro de `/sw.js?v=6` com `updateViaCache:'none'` para acelerar instalação da nova versão no PWA do iPhone e evitar políticas antigas.
3. `api/server.mjs`: políticas de cache `no-store` para `/sw.js`, o worker do Whisper e os scripts/arquivos binários `/whisper-wasm/`. Mantém ONNX e tokenizers cacheáveis. Mantém CSP `'wasm-unsafe-eval'` sem habilitar `'unsafe-eval'`.
4. `src/whisper-local.worker.ts`: prova de `WebAssembly.compile` em módulo WASM mínimo dentro do próprio Web Worker antes de carregar modelos; erros CSP retornam uma instrução clara.
5. Versão do EIXO atualizada para 0.9.2.

## Validação
- `npm run build` bem-sucedido; novo arquivo `whisper-local.worker-BZuPcNkX.js`, o hash anterior era `whisper-local.worker-B8x8KtbK.js`.
- 176 testes automatizados aprovados.
- 8 testes de guardas de produção aprovados.
- Teste Chromium com gravação falada sinteticamente em português brasileiro, processamento pelo Whisper WebAssembly local e texto final presente no campo do chat em aproximadamente 10 segundos.
- Nenhuma requisição a terceiros durante o teste de inferência, nenhuma alteração em pagamentos ou dados das contas.
- Reproduzir especificamente no Safari do dispositivo do usuário ainda é necessário, pois não há acesso ao iPhone por controle remoto neste ambiente.

## Após publicação
1. Feche o PWA EIXO por completo.
2. Abra o EIXO pelo Safari uma vez e atualize a página para a versão 0.9.2 instalar o novo Service Worker.
3. Feche novamente e abra o EIXO instalado; teste o microfone.
4. Se persistir, envie a mensagem exata; a etapa do probe ajudará a identificar CSP de Worker ou outro erro de runtime.
